# งานที่จะทำต่อ

บันทึกไว้ก่อน ยังไม่ได้เริ่มทำ

## ก่อนกล่องมาถึง

1. **คำสั่ง `firstday`**: รันครั้งเดียวแล้วเก็บ `check`, รหัส BMS, `ecus`, `dtc` และสแกน DID ช่วงหลักของ BMS
   ตัดเลข VIN/serial ออก แล้วรวมเป็นไฟล์ zip ไฟล์เดียวไว้ส่งวิเคราะห์ (ใช้ได้ทั้ง Deepal และ CR-V)
2. **สำรองข้อมูลจาก Pi ขึ้น VPS**: เมื่อ Pi ต่อ WiFi บ้านได้ ให้ส่งไฟล์ในโฟลเดอร์ข้อมูลขึ้น VPS
   (กันประวัติหายถ้าการ์ด SD เสีย) ฝั่งรถยังอ่านอย่างเดียวเหมือนเดิม
3. **ไฟล์ `.bat` สำหรับ Windows**: ดับเบิลคลิกแล้วเปิด dashboard / check ได้ ไม่ต้องพิมพ์คำสั่ง

## หลังลองกับรถจริง

4. **บันทึกการชาร์จและค่าไฟ**: kWh ที่ชาร์จเข้าแต่ละครั้ง คิดเงินตามค่าไฟ กฟภ./กฟน. (อัตราปกติและ TOU)
   สรุปรายเดือน เทียบชาร์จบ้านกับชาร์จนอกบ้าน
5. **อัตราสิ้นเปลือง kWh/100 km และระยะวิ่งจริงต่อชาร์จเต็ม**: Deepal ต้องแกะ DID เลขไมล์ก่อน
   CR-V มีเลขไมล์แล้ว ใช้ดูความเสื่อมของแบตควบคู่กับ SOH
6. **แจ้งเตือนผ่าน Telegram**: ทางเลือกเพิ่มจาก ntfy (LINE Notify ปิดบริการแล้ว)

## ก่อนเผยแพร่ (ให้เจ้าของ repo ตัดสินใจ)

7. **เปลี่ยนชื่อ repo และชื่อโปรแกรม**: ตอนนี้รองรับ CR-V แล้ว ชื่อ "Deepal S05 OBD" และแพ็กเกจ `deepal_s05`
   เริ่มไม่ตรง ถ้าจะเปลี่ยนควรทำก่อนมีคนอื่นใช้

- รหัสชิ้นส่วน BMS ของแบต 56.1 / 68.82 kWh → ใส่ใน `DEEPAL_PACKS` (`deepal_s05/vehicles.py`)
- DID แรงดัน/อุณหภูมิรายเซลล์, ค่าฉนวน, อุณหภูมิมอเตอร์/IPU/OBC ของ Deepal (ดู [REVERSE.md](../REVERSE.md))
- ยืนยันค่า CR-V กับรถสเปกไทย (ลมยาง, ความจุ Ah)
