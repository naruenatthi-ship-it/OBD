# สแกนเนอร์ OBD-II บนเว็บ

เครื่องสแกนอ่านโค้ดรถยนต์ที่ทำงานบนเว็บเบราว์เซอร์ ใช้คู่กับอุปกรณ์ **ELM327** ราคาถูก
ไม่ต้องติดตั้งแอป ไม่ต้องสมัครสมาชิก และข้อมูลไม่ถูกส่งออกไปที่ไหน

## ทำอะไรได้บ้าง

- **อ่านโค้ดปัญหา (DTC)** แยกเป็น 3 กลุ่ม: โค้ดที่บันทึกไว้, โค้ดรอยืนยัน และโค้ดถาวร พร้อมคำอธิบายภาษาไทยและคำแนะนำเบื้องต้น
- **ลบโค้ด** และดับไฟเตือนเครื่องยนต์ (Check Engine)
- **Freeze Frame** คือค่าเครื่องยนต์ ณ ตอนที่เกิดปัญหา
- **ค่าเซนเซอร์สด** เช่น รอบเครื่อง ความเร็ว อุณหภูมิน้ำ / น้ำมันเครื่อง Fuel Trim MAF และแรงดันไฟ
- **ข้อมูลรถ** ได้แก่ สถานะไฟเตือน เลขตัวถัง (VIN) โปรโตคอล และแรงดันแบตเตอรี่
- **โหมดทดลอง** ใช้รถจำลองแทนรถจริง ลองใช้งานได้ก่อนที่อุปกรณ์จะมาถึง

## เลือกซื้อ ELM327 ให้ตรงกับอุปกรณ์ที่ใช้

| ใช้งานบน | อุปกรณ์ที่ต้องซื้อ | หมายเหตุ |
| --- | --- | --- |
| มือถือ Android (Chrome) | **ELM327 Bluetooth LE (BLE 4.0)** | ⚠️ ตัวราคาถูกจำนวนมากเป็น Bluetooth Classic ซึ่งเว็บใช้ไม่ได้ ให้ดูว่าสเปกเขียนว่า **BLE / Bluetooth 4.0 / รองรับ iOS** |
| iPhone / iPad | **ELM327 Bluetooth LE** | Safari ยังไม่รองรับ ให้ใช้แอปเบราว์เซอร์ **Bluefy** (ฟรีใน App Store) แทน |
| คอม Windows / Mac / Linux (Chrome, Edge) | **ELM327 USB** หรือ **BLE** | ตัว Bluetooth Classic ใช้ได้ถ้าจับคู่ (pair) กับคอมก่อน แล้วกด "เชื่อมต่อ USB / Serial" |

รุ่นที่ใช้กันแพร่หลายและรองรับ BLE เช่น **Vgate iCar Pro BLE**, **Veepeak OBDCheck BLE** และ **vLinker MC+/FS (BLE)**
ตัวโคลน "v1.5" ราคาถูกมาก ๆ บางตัวใช้งานได้ บางตัวก็ไม่เสถียร ถ้ามีงบเพิ่มอีกนิด แนะนำให้ซื้อยี่ห้อที่รู้จัก

> รถที่ใช้ได้คือรถที่รองรับ OBD-II / EOBD ซึ่งในไทยคือรถเบนซินเกือบทุกคันที่ผลิตประมาณปี 2008 ขึ้นไป และรถดีเซลรุ่นใหม่
> พอร์ตเป็นปลั๊ก 16 ขา ส่วนใหญ่อยู่ใต้คอนโซลฝั่งคนขับ

## วิธีใช้งาน

1. เสียบ ELM327 เข้าพอร์ต OBD-II
2. บิดกุญแจไปที่ **ON** หรือติดเครื่อง
3. เปิดหน้าเว็บ แล้วกด **เชื่อมต่อ Bluetooth** (หรือ **USB / Serial**) จากนั้นเลือกอุปกรณ์
4. แอปจะค้นหาโปรโตคอลของรถ (รถรุ่นเก่าอาจใช้เวลา 5–15 วินาที) แล้วอ่านโค้ดให้อัตโนมัติ

ถ้าเชื่อมต่อ USB ไม่ได้ ให้ลองเปลี่ยนค่า **Baud** โดยส่วนใหญ่ใช้ 38400 แต่บางตัวใช้ 9600 หรือ 115200

### ข้อควรรู้เรื่องการลบโค้ด

- การลบโค้ด**ไม่ได้ซ่อมรถ** ถ้าต้นเหตุยังอยู่ โค้ดจะกลับมาอีก
- ควรบิดกุญแจ ON **โดยไม่ติดเครื่อง** ตอนลบโค้ด
- ข้อมูล Freeze Frame และผลตรวจความพร้อม (Readiness) จะถูกล้างไปด้วย ทำให้ต้องขับอีกระยะหนึ่งก่อนที่รถจะผ่านการตรวจสภาพ
- **โค้ดถาวร** (Permanent) ลบด้วยเครื่องสแกนไม่ได้ จะหายเองเมื่อระบบตรวจซ้ำแล้วผ่าน

## เปิดใช้งาน

เบราว์เซอร์จะยอมให้เว็บเชื่อมต่อ Bluetooth / USB ได้ก็ต่อเมื่อเปิดผ่าน **https://** หรือ **localhost** เท่านั้น

### บนคอมตัวเอง

```bash
npm start          # หรือ python3 -m http.server 8080
```

แล้วเปิด <http://localhost:8080> ใน Chrome หรือ Edge

### บนมือถือ (ผ่าน GitHub Pages)

รีโพนี้มี workflow `.github/workflows/pages.yml` ที่ deploy ขึ้น GitHub Pages ให้อัตโนมัติเมื่อ push เข้า `main`

1. ไปที่ **Settings → Pages** ของรีโพ แล้วตั้ง **Source** เป็น **GitHub Actions**
2. Merge โค้ดเข้า `main`
3. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโพ>/` บนมือถือ แล้ว “เพิ่มไปยังหน้าจอหลัก” ไว้ใช้ได้เลย

> GitHub Pages ใช้ฟรีกับรีโพแบบ public ถ้าเป็น private ต้องใช้แพ็กเกจ GitHub แบบเสียเงิน

## โครงสร้างโค้ด

```
index.html          หน้าเว็บ
css/style.css       หน้าตา (รองรับโหมดมืด)
js/app.js           เชื่อมหน้าจอเข้ากับตัวสแกนเนอร์
js/elm327.js        ส่งคำสั่ง AT / OBD ไปที่ ELM327 และจัดการคำตอบ
js/obd.js           ถอดรหัสข้อมูล OBD-II (PID, DTC, VIN, CAN multi-frame)
js/transports.js    ช่องทางเชื่อมต่อ Web Bluetooth และ Web Serial
js/simulator.js     รถจำลองสำหรับโหมดทดลองและการทดสอบ
js/dtc-codes.js     คำอธิบายโค้ดปัญหาภาษาไทย
tests/              ชุดทดสอบ (node --test)
```

ไม่มี dependency และไม่ต้อง build ใช้แค่ไฟล์ static

### รันชุดทดสอบ

```bash
npm test
```

### เพิ่มคำอธิบายโค้ด

แก้ที่ `js/dtc-codes.js` โดยเพิ่มรหัสลงใน `CODES` ส่วนคำแนะนำให้เพิ่มลงใน `TIPS`
โค้ดที่ไม่มีในฐานข้อมูลจะแสดงกลุ่มของระบบ พร้อมลิงก์สำหรับค้นหาเพิ่มเติม

## ข้อจำกัด

- อ่านได้เฉพาะ**ข้อมูลมาตรฐาน OBD-II** ซึ่งส่วนใหญ่เป็นของกล่องเครื่องยนต์ ส่วนโค้ดของระบบ ABS, ถุงลม และตัวถัง มักต้องใช้คำสั่งเฉพาะยี่ห้อ
- รหัสเฉพาะผู้ผลิต (เช่น P1xxx) จะไม่มีคำอธิบายละเอียด เพราะความหมายต่างกันในแต่ละยี่ห้อ

⚠️ ห้ามใช้งานขณะขับรถ ให้ผู้โดยสารเป็นคนดู หรือจอดรถก่อน
