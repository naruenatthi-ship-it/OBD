# Honda CR-V e:HEV (เจน 6, 2023 ขึ้นไป)

ใช้โปรแกรมเดียวกันและกล่อง vLinker ตัวเดิมได้ แค่ใส่ `--car crv-hybrid`
ทุกอย่างยัง**อ่านอย่างเดียว**เหมือนเดิม

> [!IMPORTANT]
> **สถานะ: เบต้า** รายการค่าและสูตรมาจาก [OBDb/Honda-CR-V-Hybrid](https://github.com/OBDb/Honda-CR-V-Hybrid)
> (สัญญาอนุญาต CC BY-SA 4.0) ซึ่งเก็บมาจากรถจริง ส่วนใหญ่เป็นรถอเมริกา
> โปรแกรมทดสอบการถอดค่ากับคำตอบจริงที่ OBDb บันทึกไว้ครบแล้ว แต่**ยังไม่ได้ลองกับ CR-V สเปกไทย**

## เริ่มใช้งาน

1. ดาวน์โหลดข้อมูลรถจาก OBDb (ครั้งเดียว ต้องต่อเน็ต) ไฟล์จะอยู่ที่ `obdb/Honda-CR-V-Hybrid.json`

   ```bash
   python -m deepal_s05 --car crv-hybrid fetch-obdb
   ```

2. เสียบกล่องที่ช่อง OBD (ใต้แผงหน้าปัดฝั่งคนขับ) กดสตาร์ทให้ขึ้น **READY**
3. ตรวจว่ารถตอบไหม:

   ```bash
   python -m deepal_s05 --car crv-hybrid --port COM5 check
   ```

4. ใช้คำสั่งอื่นได้เหมือน Deepal ทุกอย่าง แค่ใส่ `--car crv-hybrid` ไว้หน้าคำสั่ง:

   ```bash
   python -m deepal_s05 --car crv-hybrid --port COM5 dashboard
   python -m deepal_s05 --car crv-hybrid --port COM5 checkup
   python -m deepal_s05 --car crv-hybrid --port COM5 dtc
   ```

ตัวเลือกเพิ่ม:

- `--year 2024` ปีรุ่นรถ คำสั่งบางตัวต่างกันตามปี ถ้าไม่ใส่จะลองอ่านทุกแบบ (ช้ากว่านิดหน่อย)
- `--obdb ไฟล์.json` ถ้าเก็บไฟล์ข้อมูลไว้ที่อื่น (ใช้กับ `fetch-obdb` ได้ด้วย)

## ค่าที่อ่านได้

| กลุ่ม | ค่า |
|---|---|
| 🔋 แบตไฮบริด | SOC, แรงดัน, กระแส, **แรงดันรายเซลล์ 72 เซลล์**, SOC เซลล์สูงสุด/ต่ำสุด, อุณหภูมิโมดูลแบต, อุณหภูมิน้ำหล่อเย็นแบต, รอบพัดลมแบต |
| ⚡ ระบบไฮบริด | อุณหภูมิ DC-DC, กระแสอินเวอร์เตอร์มอเตอร์, รอบเจนเนอเรเตอร์ |
| 🔧 เครื่องยนต์ | อุณหภูมิน้ำหล่อเย็น, อุณหภูมิน้ำมันเครื่อง, จำนวนครั้งที่จุดระเบิดพลาดรายสูบ, อุณหภูมิแคตาไลติก |
| 🚗 อื่นๆ | เลขไมล์, น้ำมันที่เหลือ, ลมยาง 4 ล้อ, อุณหภูมิในห้องโดยสาร/นอกรถ |
| 🩺 โค้ดปัญหา | อ่านจากทุกกล่อง ECU (ไม่ลบโค้ด) |

นอกจากแรงดันรายเซลล์แล้วมีประมาณ 120 ค่า ค่าที่ยังไม่มีชื่อภาษาไทยจะแสดงชื่อภาษาอังกฤษตาม OBDb
ค่าบางตัวตอบเฉพาะบางปีรุ่นหรือบางสถานะ (เช่น ตอนเครื่องยนต์ติด) ถ้าขึ้น "ไม่ตอบ" ก็เป็นเรื่องปกติ

**ยังไม่ได้ยืนยันเลย:** ลมยาง (ยังไม่มีคำตอบจากรถจริงให้เทียบ) และความจุแบต Ah (รถจริงที่ OBDb บันทึกไว้อ่านได้ 0)

**ยังไม่มี:** สุขภาพแบตเป็น % (SOH), ค่าสดของ ABS/ถุงลม/พวงมาลัย/Honda Sensing
ถ้าจะหาเพิ่ม ดูหัวข้อ "แกะค่าเพิ่มเอง" ด้านล่าง

## เกณฑ์แจ้งเตือน

ค่าเริ่มต้นต่อไปนี้ตั้งจากหลักทั่วไปของแบตลิเทียมไอออน **ไม่ใช่สเปกของ Honda**
ปรับเองได้ในไฟล์ `--signals` (ดูหัวข้อ "แจ้งเตือน" ใน[คู่มือการใช้งาน](USAGE.md))

| ค่า | ⚠️ ควรเฝ้าดู | 🔴 ควรให้ช่างตรวจ |
|---|---|---|
| แรงดันเซลล์สูงสุด | > 4.15 V | > 4.2 V |
| แรงดันเซลล์ต่ำสุด | < 3.3 V | < 3.0 V |
| ส่วนต่างแรงดันเซลล์ | > 50 mV | > 100 mV |
| อุณหภูมิแบต (โมดูล) | > 45 °C | > 55 °C |
| อุณหภูมิน้ำหล่อเย็นแบต | > 45 °C | > 55 °C |
| อุณหภูมิ DC-DC | > 80 °C | > 95 °C |
| ลมยาง | < 200 kPa (29 psi) | < 170 kPa (25 psi) |
| แบต 12V ตอนรถ READY | < 13.0 V | < 12.0 V |

ถ้าแบตร้อนบ่อยหรือพัดลมแบตหมุนแรงตลอด ให้ศูนย์ตรวจระบบระบายความร้อนของแบตไฮบริด

## ใช้กับ Raspberry Pi

Pi หนึ่งตัวติดได้คันเดียว ถ้าจะติดทั้งสองคันต้องมี Pi และกล่อง OBD อย่างละชุด
ถ้าจะย้ายกล่องไปมาระหว่างรถก็ทำได้ แต่ต้องจับคู่บลูทูธใหม่และเปลี่ยนตั้งค่าทุกครั้ง

หลังติดตั้งตาม [pi/README.md](../pi/README.md) แล้ว ให้ดาวน์โหลดข้อมูลรถไว้ในโฟลเดอร์ข้อมูลของ Pi:

```bash
cd /opt/deepal-obd
python3 -m deepal_s05 --car crv-hybrid --obdb /var/lib/deepal-obd/Honda-CR-V-Hybrid.json fetch-obdb
sudo nano /etc/default/deepal-obd
```

แก้บรรทัด `OBD_OPTIONS` เป็น:

```
OBD_OPTIONS="--car crv-hybrid --obdb /var/lib/deepal-obd/Honda-CR-V-Hybrid.json"
```

แล้ว `sudo systemctl restart deepal-obd` โหมดอัตโนมัติใช้หลักเดิม: แบต 12V ≥ 13.0 V แปลว่ารถ READY
(DC-DC กำลังชาร์จแบต 12V) ตอนรถดับจะไม่ส่งอะไรเข้ารถเลย

## แกะค่าเพิ่มเอง

CR-V ใช้ CAN แบบ 29 บิต header จะยาว 8 ตัว เช่น `18DA01F1` (ถาม ECU `01`) และคำตอบมาจาก `18DAF101`

```bash
python -m deepal_s05 --car crv-hybrid --port COM5 ecus --save ecus.csv
python -m deepal_s05 --car crv-hybrid --port COM5 discover --header 18DA01F1 --ranges 2000-20FF --save scan.csv
```

- `ecus` ไล่ถาม `18DA00F1`–`18DAFFF1` (256 header ประมาณ 2–3 นาที)
- ค่าที่ OBDb ใช้ส่วนใหญ่อยู่ในช่วง DID `2000`–`20FF`, `2600`–`26FF`, `6000`–`60FF` และ `7000`–`70FF`
  ลองไล่ช่วงเหล่านี้ใน ECU อื่นที่ `ecus` เจอได้
- ขั้นตอนที่เหลือ (`scandiff`, `record`, `correlate`) เหมือน [คู่มือวันแกะข้อมูล](../REVERSE.md) ทุกอย่าง
  แค่เปลี่ยน header เป็นแบบ 29 บิต
- ถ้าแกะได้ค่าใหม่ ส่งกลับไปที่ [OBDb](https://github.com/OBDb/Honda-CR-V-Hybrid) ได้ด้วย คนอื่นจะได้ใช้
